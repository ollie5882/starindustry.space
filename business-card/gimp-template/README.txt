STAR INDUSTRY — BUSINESS CARD / GIMP TEMPLATE
=============================================

FILES
  StarIndustry_Card_FRONT_editable.psd   Front (phoenix + wordmark)
  StarIndustry_Card_BACK_editable.psd    Back (details + QR)
  fonts/                                 The three brand fonts (install these first)

CANVAS / PRINT SPEC
  Size in pixels : 1075 x 720 px
  Resolution     : 300 DPI  (set this in GIMP: Image > Print Size > 300)
  Physical size  : 91 x 61 mm  = 85 x 55 mm card + 3 mm bleed on every edge
  Trim line      : cyan dashed guide
  Safe area      : magenta dashed guide (keep all text inside this)

BEFORE YOU START — INSTALL THE FONTS
  Double-click each .ttf in the fonts/ folder and click "Install":
    - Bebas Neue   (the STAR INDUSTRY wordmark)
    - Space Mono   (title, contact details, tagline)
    - DM Sans      (the name)
  Restart GIMP after installing so it picks them up.

LAYERS (each element is its own layer so you can move / recolour / hide it)
  FRONT: Guides · Tagline · Phoenix logo · Ember glow · Starfield · Background
  BACK : Guides · SCAN ME label · QR code · QR chip · Phone · Email + Website
         · Title · Name · Divider · Wordmark · Phoenix emblem · Background

  The "Guides (trim+safe)" layer is only a visual aid — hide or delete it
  before exporting for print.

EDITING TEXT
  Text is on individual raster layers. To change wording (e.g. the phone
  number on the "Phone" layer): hide that layer, then use GIMP's Text tool
  with the matching font, size and the amber colour #FFAB40 to retype it.

BRAND COLOURS
  Navy      #031827      Amber        #FFAB40
  Panel     #0A2540      Amber light  #FFC172
  Sky       #7DD3FC      Slate        #94A3B8
  White     #FFFFFF

EXPORTING FOR PRINT
  1. Hide the Guides layer.
  2. File > Export As > .pdf (or .tiff / .png) at 300 DPI.
  3. Send front and back to the printer. Keep the 3 mm bleed; the printer
     trims to the cyan line.

TIP
  If you'd rather I make edits and regenerate the print-ready PDF for you,
  just tell me what to change (phone number, tagline, title, etc.).
